01 / RESEARCH OVERVIEW

From known patterns
to anomalous behaviour.

The project explores the challenge of identifying malicious network activity that differs from attack classes represented in supervised training data. It combines a supervised classifier with an unsupervised anomaly signal and provides a software architecture for model serving and analyst-facing workflows.

Network-flow analytics

Uses structured flow features to represent network activity for machine-learning based detection.

Hybrid risk scoring

Combines attack probability and anomaly evidence into one score to support triage and review.

Zero-day evaluation

Leave-one-attack-family-out evaluation is intended to test generalisation to a family excluded from training.

02 / PROPOSED METHODOLOGY

Two complementary detection signals.

The hybrid scoring design blends the XGBoost attack probability with an Isolation Forest anomaly percentile. The blend weight and decision threshold should be tuned using validation data and then frozen before held-out testing.

f(x) = w · p(x) + (1 − w) · s(x)
STEP A

Isolation Forest

Estimates how unusual a flow is relative to the learned benign traffic distribution.

STEP B

XGBoost classifier

Estimates attack probability from flow features and the anomaly signal.

STEP C

Risk interpretation

Maps the blended score to a risk scale for downstream review and prioritisation.
